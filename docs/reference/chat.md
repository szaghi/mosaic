# mosaic chat

A conversation with your indexed papers: each question retrieves papers as [`mosaic ask`](./ask) does, and the
earlier turns stay in context.

## Usage

```bash
mosaic chat                       # over the whole index
mosaic chat -q "hall thruster"    # only the papers matching a query
mosaic chat --from refs.bib       # only the papers of a BibTeX file
mosaic chat --mode gaps           # start in another mode
```

## Behaviour

Commands inside the session:

| Command | Effect |
|---|---|
| `/mode MODE` | switch to `synthesis`, `gaps`, `compare` or `extract` |
| `/sources` | the papers retrieved for the last question |
| `/clear` | forget the conversation so far |
| `/quit` | leave (Ctrl-D and Ctrl-C too) |

See also: [tutorial 9](/tutorial/09-library), [asking your library](/guide/rag).

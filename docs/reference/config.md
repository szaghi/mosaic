# mosaic config

Shows and changes the configuration in `~/.config/mosaic/config.toml`. Run it with no options, or with
`--show`, to print the configuration as JSON.

## Usage

```bash
mosaic config --show
mosaic config --unpaywall-email you@university.edu --download-dir ~/papers
mosaic config --ss-key KEY --ncbi-key KEY
mosaic config --disable-source dblp --disable-source hal
mosaic config --filename-pattern "{year}_{author}_{title}"
mosaic config --llm-provider openai --llm-base-url http://localhost:11434/v1 --llm-api-key ollama --llm-model qwen3:8b
mosaic config --embedding-model qwen3-embedding:0.6b --embedding-base-url http://localhost:11434/v1 --embedding-api-key ollama
```

## Behaviour

Options can be combined; the file is written once.

| Purpose | Options |
|---|---|
| Keys | `--elsevier-key`, `--ss-key`, `--ncbi-key` (PubMed and PubMed Central), `--core-key`, `--ads-key`, `--ieee-key`, `--springer-key`, `--scopus-key`, `--scopus-inst-token`, `--zenodo-key`, `--zotero-key` (also finds and saves your Zotero user ID) |
| Open access | `--unpaywall-email` |
| Sources | `--enable-source NAME`, `--disable-source NAME` (repeatable; config names such as `semantic_scholar`, `europepmc`) |
| Paths and names | `--download-dir`, `--db-path`, `--filename-pattern`, `--rate-limit-delay` |
| Obsidian | `--obsidian-vault`, `--obsidian-subfolder`, `--obsidian-filename-pattern`, `--obsidian-tag` (repeatable, replaces the list), `--obsidian-wikilinks/--no-obsidian-wikilinks` |
| LLM | `--llm-provider` (`openai` or `anthropic`), `--llm-api-key`, `--llm-model`, `--llm-base-url` (any OpenAI-compatible server: Ollama, LM Studio, llama.cpp) |
| Embeddings and retrieval | `--embedding-model`, `--embedding-base-url`, `--embedding-api-key`, `--rag-top-k`, `--rag-auto-index`, `--chunk-overlap`, `--full-text-index` |
| PEDro | `--pedro-fair-use`, `--pedro-fetch-details`, `--pedro-rate-limit-delay` |

Placeholders of `--filename-pattern`: `{year}` (`0000` when unknown), `{source}`, `{author}` (the first word of the
first author's name as the source writes it: a family name for "Family, Given" sources, a given name for
"Given Family" ones), `{title}` (up to 60 characters), `{doi}`, `{journal}` (`no_journal` when unknown).

Keys without an option (custom sources, `rag.citations.*`, `rag.chunk_size`, Zotero `user_id`, and others) are set by
editing `~/.config/mosaic/config.toml`: see [configuration](/guide/configuration).

Exit code 1 for an unknown source name.

See also: [configuration](/guide/configuration), [installation](/guide/installation).

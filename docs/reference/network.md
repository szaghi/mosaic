# mosaic network

Analyses the citation graph of your cache: the most connected papers, clusters of papers that cite each other,
and exports for Gephi, D3, Graphviz or Mermaid.

## Usage

```bash
mosaic network --top 10                                  # the most connected papers
mosaic network --query "hall thruster" --depth 2         # the neighbourhood of matching papers
mosaic network --query "thruster" --cluster --top 3      # clusters, and the hubs of each
mosaic network --min-connections 3 -o graph.json         # node-link JSON (D3, Gephi)
mosaic network --query "plume" -o plume.gv               # Graphviz
mosaic network --query "plume" -o plume.md               # a Mermaid diagram
```

## Behaviour

The edges come from [`mosaic index --enrich-citations`](./index-command); without them the graph is empty.

`--query` seeds the graph with the cached papers matching it and follows citations `--depth` hops (default 2);
with no query the whole graph is used. `--min-connections` drops papers with fewer edges.

`--cluster` uses Louvain community detection when networkx is installed (the `analysis` extra) and connected
components otherwise.

`--output` writes `.json` (node-link), `.gv`/`.dot` (Graphviz) or `.md`/`.markdown` (Mermaid); the format follows
the extension.

See also: [tutorial 10](/tutorial/10-citations), [citation network](/guide/network),
[citation graph](/guide/citation-graph).

# mosaic skill

Installs the Claude Code skill bundled with mosaic: a `/mosaic` command that knows every command, source and
option, for asking an agent to build a bibliography.

## Usage

```bash
mosaic skill install            # into ./.claude/skills/mosaic/ (this project)
mosaic skill install --global   # into ~/.claude/skills/mosaic/ (every project)
mosaic skill show               # print the skill
```

## Behaviour

`install` overwrites an existing copy, so rerun it after upgrading mosaic. Open a new Claude Code session to load
the skill.

See also: [agents and Claude Code](/guide/agent-workflows), [scripting recipes](/cookbook/scripting).

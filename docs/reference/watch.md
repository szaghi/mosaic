# mosaic watch

Saved searches. A watch remembers every paper it has returned; `mosaic watch run` repeats the search and shows
only the papers it has not seen before.

## Usage

```bash
mosaic watch add "hall thruster anomalous transport" --name hall-transport --source arxiv
mosaic watch list                         # every watch, with the papers seen and the last run
mosaic watch run                          # run them all, show what is new
mosaic watch run hall-transport --download  # one watch, and fetch the new PDFs
mosaic watch run --json                   # for cron jobs and scripts
mosaic watch remove hall-transport        # delete the watch and its history
```

## Behaviour

`watch add` runs the search once and records its results as the baseline, so the first `watch run` reports only
papers published (or indexed by the sources) after that. The filters are the ones of `search` and are saved with
the watch.

`watch run` with no names runs every watch. A paper counts as new for a watch when that watch has never returned
its uid; another watch, or a plain search, does not affect it. New papers are saved in the cache.

Exit code 1 when a named watch does not exist.

See also: [tutorial 7](/tutorial/07-following), [watches](/guide/watch), [recipes](/cookbook/monitoring).

### `mosaic watch add`

Save a watch and record its current results as the baseline.

```
mosaic watch add [OPTIONS] QUERY
```

| Argument | Value | Description |
|---|---|---|
| `QUERY` | `TEXT` | Search query to watch |

| Option | Value | Default | Description |
|---|---|---|---|
| `--name`, `-n` | `TEXT` |  | Unique watch name |
| `--max`, `-m` | `INTEGER` | `25` | Max results per source |
| `--source`, `-s` | `TEXT` |  | Restrict to one source shorthand |
| `--year`, `-y` | `TEXT` |  | Year filter: 2020, 2020-2024, 2020,2022 |
| `--author`, `-a` | `TEXT` |  | Author name filter (repeatable) |
| `--journal`, `-j` | `TEXT` |  | Journal filter |
| `--field` | `TEXT` | `all` | all \| title \| abstract |
| `--raw-query` | `TEXT` |  | Raw query override |
| `--oa-only` |  |  | Open-access papers only |

### `mosaic watch list`

List saved watches.

```
mosaic watch list [OPTIONS]
```

### `mosaic watch remove`

Delete a watch and its history of seen papers.

```
mosaic watch remove [OPTIONS] NAME
```

| Argument | Value | Description |
|---|---|---|
| `NAME` | `TEXT` | Watch name |

### `mosaic watch run`

Re-run watches and show only papers they have not returned before.

```
mosaic watch run [OPTIONS] [NAMES]...
```

| Argument | Value | Description |
|---|---|---|
| `NAMES` | `TEXT` | Watch name(s) to run; default: all (optional) |

| Option | Value | Default | Description |
|---|---|---|---|
| `--download`, `-d` |  |  | Download PDFs of new papers |
| `--json` |  |  | Emit JSON (for cron jobs and scripts) |

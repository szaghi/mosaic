# mosaic notebook

Creates a Google NotebookLM notebook from a search, or from a folder of PDFs, and queues the artifacts you ask
for: an audio overview, a video, slides, a quiz and more.

## Usage

```bash
mosaic notebook create "Hall thrusters" --query "hall thruster anomalous transport" --oa-only
mosaic notebook create "Hall thrusters" --query "hall thruster" -y 2020-2025 --oa-only --podcast --briefing
mosaic notebook create "My library" --from-dir ~/mosaic-papers --slide-deck --mind-map
```

## Behaviour

Needs the `notebooklm` extra and a one-time `notebooklm login`. NotebookLM has no official API: the integration
uses the unofficial `notebooklm-py` client, and can break when Google changes the service.

Give exactly one of `--query` or `--from-dir`. With `--query`, mosaic searches, downloads the PDFs and imports
them; the search filters (`-y`, `-a`, `-j`, `-f`, `--raw-query`) apply only there. `--oa-only` and `--pdf-only`
apply in both modes.

The artifact flags queue generation in NotebookLM after the import; the artifacts appear in the notebook when
Google finishes them.

See also: [NotebookLM](/guide/notebooklm).

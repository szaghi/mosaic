# mosaic similar

Finds papers related to one paper, given its DOI or arXiv ID. No query needed: the related works come from
OpenAlex and, when a Semantic Scholar key is set, from Semantic Scholar's recommendations.

## Usage

```bash
mosaic similar 10.1063/1.4972269                           # related to one DOI
mosaic similar arxiv:2304.06563 --max 20 --sort citations  # an arXiv paper, most cited first
mosaic similar 10.1063/1.4972269 --oa-only --download      # fetch the open ones
mosaic similar 10.1063/1.4972269 -o related.bib            # save as BibTeX
mosaic similar 10.1063/1.4972269 --json                    # JSON, with the seed title
```

## Behaviour

`IDENTIFIER` is a bare DOI, `doi:10.xxx`, or `arxiv:NNNN.NNNNN` (either case). OpenAlex `related_works` is always
queried and needs no key; Semantic Scholar recommendations are added when `semantic_scholar.api_key` is set
(`mosaic config --ss-key KEY`). Results are merged by the same rule as `search` and saved in the cache.

The title of the seed paper is printed above the table, and is the `seed` field of `--json` output. Exit code 1 if
the paper is not found.

See also: [tutorial 7](/tutorial/07-following), [similar papers](/guide/similar),
[recipes](/cookbook/monitoring).

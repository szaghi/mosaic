# mosaic cite

Prints a citation for a DOI: BibTeX, or a formatted reference in APA, MLA, Chicago, Harvard or Vancouver style.

## Usage

```bash
mosaic cite 10.3389/fphy.2019.00140                      # BibTeX
mosaic cite 10.3389/fphy.2019.00140 --style apa          # a formatted reference
mosaic cite https://doi.org/10.3389/fphy.2019.00140 -s vancouver
mosaic cite 10.3389/fphy.2019.00140 --style apa --copy   # and to the clipboard
```

## Behaviour

| Style | Made by | Network |
|---|---|---|
| `bibtex` (default) | mosaic, from the paper's metadata | only when the DOI is not in the cache (Crossref lookup) |
| `apa`, `mla`, `chicago`, `harvard`, `vancouver` | Crossref content negotiation at doi.org | always |

The DOI may be bare, `doi:`-prefixed or a `https://doi.org/` URL. A DOI looked up on Crossref is saved in the cache.

`--copy` tries `pyperclip`, then `pbcopy` (macOS), `clip` (Windows), `xclip` or `xsel` (Linux). If none works the
citation is still printed, with a warning.

Exit code 1 for an unknown style, a DOI that cannot be parsed or is not found, or no network.

See also: [tutorial 6](/tutorial/06-exporting), [exporting recipes](/cookbook/exporting).

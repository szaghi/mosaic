# mosaic ui

Starts the web interface: search, filter, download and export from a browser page.

## Usage

```bash
mosaic ui                     # http://127.0.0.1:5555, opened in your browser
mosaic ui --port 8080
mosaic ui --host 0.0.0.0      # reachable from other machines on your network
mosaic ui --no-browser        # start the server only
```

## Behaviour

Needs the `ui` extra (Flask and Waitress). The server is Waitress; `--debug` runs Flask's development server with
reloading instead. The web interface uses the same config and cache as the command line.

With `--host 0.0.0.0` anyone who can reach the port can use the interface, and your saved keys and sessions with
it: there is no login.

See also: [web interface](/guide/web-ui).
